# Employee Stats — CLOSING TEAM

Сайт для отображения статистики сотрудников (день/неделя/лично) + админ-панель.

## Локальный запуск (Python 3.13.1)
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate

pip install -r requirements.txt
python main.py
# Открой: http://127.0.0.1:8000
```

**Пароль админки:** `admin`
